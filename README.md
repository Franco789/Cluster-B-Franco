# Atlas Neurosemiológico y Farmacológico del Clúster B

Plataforma interactiva en Streamlit para el análisis dimensional (HiTOP / DSM-5 Sección III), conectómica funcional y psicofarmacología de guardia en trastornos del Clúster B.

## Ejecución local
```bash
pip install -r requirements.txt
streamlit run app.py
```
